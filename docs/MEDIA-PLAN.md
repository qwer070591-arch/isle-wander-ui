# Media Plan — Phase 0

本階段只定義攝影方向、槽位與授權流程；**沒有抓圖、生成正式圖片或選定旅宿照片**。所有對外可見的真實地點與住宿影像，發布前必須有可用授權、來源紀錄與適合裁切的版本。

## 攝影語言

以真實台灣的自然光與地方生活為核心。光線偏晨昏、陰天與柔和側光；人物可入鏡，但須有情境與肖像權處理。避免高飽和濾鏡、過度空拍、把居住街區塑成「無人秘境」、把 AI 生成旅宿內裝當真實場景。每個地點至少一張建立地理感的廣角、一張保留人的尺度與生活細節；不要只收集相似的山海大片。

| 主題 | 影像重點 | 避免 |
|---|---|---|
| 山脈 | 步道、地形層次、雲霧與人行尺度 | 把受管制區域當自由進入景點 |
| 東海岸 | 海岸線、聚落與道路的關係 | 只剩抽象海景，無法辨識地方 |
| 湖泊與森林 | 水面反光、樹冠與安靜停留 | 假造地點或季節 |
| 歷史街區 | 建築材料、街道使用與當地商家 | 未授權的店家／私人空間特寫 |
| 地方生活 | 市場、工藝、飲食與互動 | 未取得肖像同意的可辨識人物 |
| 設計旅宿 | 真實房型、公共空間與周邊環境 | AI 示意圖冒充實際設施 |

## 首頁媒體槽位

| 槽位 | 建議數量 | 桌面比例 | 手機策略 | 優先級／fallback |
|---|---:|---|---|---|
| Hero | 1 組 | 約 7:6 | 獨立 4:5 裁切或圖片，保留人物／地形焦點 | 首屏優先；失敗為 Forest 色塊與文字 |
| Region | 5 | 3:4、4:3 混排 | 16:9 短裁切 | 延遲；色塊 + 區域名 |
| Destination | 3 | 主 4:3、副 16:9 | 主 4:3、副 16:9 | 延遲；文字卡 |
| Stay | 2 | 4:5、3:2 | 4:3 | 無合法真實照時改純色文字卡 |
| Mood | 3–4 | 3:4／4:3 | 4:3 | 可用文字與色塊建立主題 |
| Story／Closing | 0–1 | 視文章而定 | 依內容裁切 | 純文字版面可成立 |

## 素材紀錄

每張媒體建立與 `MediaAsset` 對應的紀錄：`assetId`、顯示地點／主體、攝影師／權利人、原始 URL、授權或書面許可、允許用途、是否要求署名、人物／場所同意、取得日期、核對日期、桌面與手機裁切、alt、使用頁面。權利不明的圖片不得進正式素材庫。若使用圖庫，逐張查核該圖的授權與限制，不以「免費圖庫」四字概括。商家提供照片也需確認網站展示、裁切、署名與期限。

來源優先順序：自行拍攝或正式委託 → 商家／地方單位書面授權 → 逐張驗證授權的可信圖庫。參考站 [Hôtel Weekend](https://www.hotel-weekend.com/) 只作編輯感觀察，**不下載或重用其圖片**。AI 圖若作 moodboard，檔名與畫面註明「概念示意」，不得充當可辨識真實住宿或景點。

## 製作與效能

Phase 1 選圖後輸出桌面及手機裁切，優先 AVIF／WebP，保留 JPEG fallback 視支援需求；設定 `width`、`height` 或 `aspect-ratio`。以實際畫面尺寸決定 `srcset/sizes`，首屏 Hero 預載但其他圖片延遲載入；在 390px 實機／模擬低速下檢查載入與裁切。圖片上的文字一律另以 HTML 呈現。對比在最終照片與遮罩上驗證。

## 圖片採購前待確認

1. 初期是否有自行拍攝素材與明確權利人。
2. 住宿業者是否願意授權照片與名稱、官網連結。
3. 是否允許付費圖庫及可用預算；此決策會影響首頁 Hero 品質與上線速度。
