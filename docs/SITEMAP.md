# Sitemap 與導航

路由採 Vue Router；以下為 Phase 1 的建議資訊架構。`/` 是首頁；清單路由採固定英文名詞，詳情用穩定 slug。導覽用中文標籤，網址維持英文。

| 路由 | 頁面／主要目標 | 內容結構 | 主要去向 |
|---|---|---|---|
| `/` | Home：建立品牌印象、開始探索 | 七段編輯式首頁 | 區域、景點、住宿、故事、規劃 |
| `/destinations/` | Destinations：從地理位置選城市 | 區域入口、城市清單、簡介 | `/destinations/:slug/`、景點篩選 |
| `/destinations/:slug/` | 城市頁：理解地方特色 | 首圖、短導言、相關景點／住宿／故事 | 對應詳情、加入行程 |
| `/attractions/` | Explore Attractions：找符合偏好的景點 | 搜尋、區域／類型篩選、結果 | `/attractions/:slug/`、收藏 |
| `/attractions/:slug/` | 景點詳情：評估是否值得前往 | 圖片、地點、特色、資料來源／更新、相關內容 | 收藏、加入行程、官方連結 |
| `/stays/` | Curated Stays：探索設計住宿 | 編輯前言、城市／特色篩選、住宿卡 | `/stays/:slug/` |
| `/stays/:slug/` | 住宿詳情：了解特色與來源 | 圖片、介紹、地點、外部官網及免責 | 收藏、外部官網 |
| `/stories/` | Travel Stories：讀地方故事 | 主題故事、文章列表 | `/stories/:slug/` |
| `/stories/:slug/` | 文章頁：完整閱讀 | 標題、作者／來源、日期、段落、相關地點 | 目的地、景點、規劃 |
| `/planner/` | Trip Planner：組裝與保存個人行程 | 行程列表或編輯器、每日項目、localStorage 狀態 | 景點探索、收藏 |
| `/favorites/` | Favorites：重訪收藏 | 依城市／景點／住宿／故事分組 | 對應詳情、加入行程 |
| `/:pathMatch(.*)*` | 404：恢復導航 | 簡短說明、回首頁／探索 | `/`、`/destinations/` |

## 全域導航

桌面 Header 第一層：`目的地`、`探索景點`、`精選住宿`、`旅行故事`、`我的行程`、`收藏`；Logo 回首頁。搜尋是獨立可見入口，預設搜尋城市與景點，結果可跳轉對應清單並帶查詢參數（例如 `/attractions/?q=海岸&region=east`）。手機 Drawer 保持同順序；搜尋按鈕始終在 Header 可見。Footer 重複主要入口與素材／授權資訊。

## 區域與關聯

區域先採 `north / central / south / east / islands` 五組，城市必須只屬於一個主要區域；離島含澎湖、金門、連江。這是**編輯分組**，不是行政分類。城市、景點、住宿與故事以 ID 關聯，不靠顯示名稱連結。城市詳情頁是否在 Phase 1 完成由路線圖定義，但路由與資料模型先保留。

## 導航狀態與例外

清單篩選寫入 query，重新整理與返回可保留條件；未知 slug 顯示 404，不顯示空白頁。清單零結果給清除篩選；JSON 載入失敗給重試。收藏與行程不需要登入，但只在目前瀏覽器保存；清除瀏覽器資料會遺失。外部住宿官網須標示離站，新分頁開啟時使用 `rel="noopener noreferrer"`。
